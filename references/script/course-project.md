# 学生课程设计汇报

## 中期检查

交代课程任务、团队分工和当前阶段的目标。用已有产物说明实际进度，选一个能代表现阶段工作的方法或案例，讲清楚输入、操作和结果。最后说明当前卡在哪个问题、这个问题影响什么、下一阶段将如何验证。

进度数字配上单位和范围，例如完成了多少功能、覆盖了哪些测试场景。课程要求中的交付项可以作为组织线索。

## 期末答辩

开场简短交代项目目标、交付成果和发言人负责的部分。功能适合现场展示时，可以从使用场景进入演示，再讲关键实现。以研究、数据或评测为主时，可以从一项有代表性的结果进入案例，再讲设计和验证方法。

讲完机制后交代实际验证范围。项目包含多人汇报时，交接句说明下一位同学会继续讲的内容。

## 答辩追问

根据课题内容准备老师可能问的问题，例如如何证明达到课程目标、个人负责了什么、为什么选择这一方案、结果如何复现、还有哪些情况需要验证。回答引用当前项目的演示、测试或明确记录。
