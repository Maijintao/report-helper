# 工作项目汇报

## 进度汇报

开场交代当前目标和阶段结果。用里程碑、上线记录、使用数据或交付物说明进展。对需要听众参与的问题，讲清楚影响、当前处理方式、需要谁决定什么，以及资料中已经约定的时间。

## 成果验收或技术评审

从业务场景、交付目标或需要评审的决定切入。按听众关心的问题组织结果和证据。面向负责人时，突出影响和需要确认的决定。面向技术同事时，交代关键机制、方案取舍、验证环境和适用条件。

使用指标时交代统计范围、时间和比较基准。区分测试结果、试运行和生产结果。把已交付的内容、仍待验证的范围和后续安排分别说清楚。

## 追问准备

从本次汇报的结论出发，准备成本、验证方法、使用范围、运行风险和负责人的追问。对尚未确认的指标或承诺，说明现有依据和确认方式。面向外部听众时，核对材料的公开范围。
