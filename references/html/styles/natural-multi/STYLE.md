# 自然多色风（多色选择）

这套风格的核心是「配色可选」：先按 [色板表](palettes.md) 从 17 套里挑一套，再开始做页面。配色是皮肤，选定后整份汇报只用这一套，不逐页换色；视觉语言和版式骨架则固定不变。

骨架是「一组带角色的配色 + 一页一种组件」。视觉语言是粗描边、平涂、方角、粗标题，外加一层手绘抖动。适合观点表达、课程汇报、作品集、社团宣讲；不适合需要精确读数的数据密集页。

模板里按 `[` / `]` 或点配色库的小卡就能实时换色，方便对着项目挑；挑定之后把选中的那套写进 `:root`，整份汇报固定用它。

## 视觉语言

- **粗描边**：卡片、按钮、图表都用 2px 墨色描边，圆角 `.9cqw`，没有阴影、没有渐变。
- **方角按钮**：圆角 `.25cqw`，实心强调色，按钮上的字用该套的「按钮字」色，不放图标。
- **粗标题**：无衬线 800 字重，行高 1.1–1.2，字距收紧。中文用苹方一类黑体，不嵌字体。
- **蜡笔抖动**：所有插画和手绘线条走同一层 SVG 滤镜，矢量边被噪点位移成手绘边。

```svg
<filter id="crayon" x="-15%" y="-15%" width="130%" height="130%">
  <feTurbulence type="fractalNoise" baseFrequency="0.038" numOctaves="2" seed="7" result="n"/>
  <feDisplacementMap in="SourceGraphic" in2="n" scale="2.8" xChannelSelector="R" yChannelSelector="G"/>
</filter>
```

涂鸦用 `<symbol>` 做成可复用的组件，填充色走 `var(--accent)` / `var(--soft)` / `var(--mint)`，切配色时一起变。至少备齐：太阳脸、对话气泡、闪光、波浪下划线、箭头、人物头像、勾叉、几种物件图标。

## 组件库：一页一种

**这是这套风格最重要的一条规则。** 每页只用一个组件类型，不许把同一个图表铺到每一页；也不许每页都退化成「标题 + 三个文字块」。

| 组件 | 构成 | 适合承载 |
| --- | --- | --- |
| Hero | 大标题 + 手绘波浪下划线 + 主按钮 + 线稿插画（窗口、太阳脸、气泡） | 封面、开场 |
| 故事图 | 两行「角色头像 + 走势线 + 说明」，其中一行压一张事件卡；数据点用圆片或锯齿折线 | 讲清「同一件事，两种读法」 |
| Bento 网格 | 1 大 2 小的不对称格子，三种不同底色，图标放进圆形徽章 | 并列的几方、几种状态 |
| 时间轴 + 改写卡 | 左侧竖线串圆点讲步骤，右侧 before/after 两张卡加一支手绘箭头 | 方法、流程，顺手给一个具体例子 |
| 定价卡 | 两张卡，一张描边一张实心，勾叉清单，各自一个按钮 | 两种做法的对照 |
| 配色库 | 每套配色一张小卡，四枚叠起来的圆点，卡片底色和描边用它自己的颜色 | 展示可选皮肤（只用于选色，交付前删掉这一页） |
| 页脚 | CTA + 多栏链接 + 版权线 | 收尾 |

## 构图

- **两侧分量要接近**。时间轴那类单侧窄内容，另一侧必须放一个同风格组件（改写卡、对照卡、示意图），不能留大片空白。
- 封面和内容页用不同的构图：封面左右分栏，内容页可以满版、可以四格，翻页要有节奏变化。
- 一页一个结论。组件是给结论服务的，不要为了填满而堆组件。
- 窄窗口下 16:9 舞台改为单列竖排，字号换回 rem 档，组件逐个往下堆，不靠裁切省空间。模板已在 44rem 处写好这套断点。

## 文字与底色

遵守 [HTML 共用基准](../../design-baseline.md) 的「底色与文字」：

- 浅底配深字，饱和底或暗底配浅字，文字不跨越底色交界。
- 强调色只用在浅底或它的配套按钮字上；深色页里的强调色改用该套的浅色值。
- 卡片底色由 `color-mix` 从底色推导，深色页自动变亮、浅色页自动变灰。

## 数字

组件里的数字如果来自假设，必须在图表或页头标明「示意 / 非实测」，并留出替换位置。把示意值写成实测结果是内容事故，不是设计问题。

## 动效

- 每个组件配自己的入场：故事图的圆片逐颗弹出、bento 的徽章弹入、时间轴圆点弹出、定价卡两张错开落下。
- 顺序按讲述走，不要给每页元素套同一个淡入上浮。
- 动效用 GSAP 时间线实现，交付前跑 [强制内联 GSAP](../../workflow.md#交付前强制内联-gsap) 把发行文件整段内联并保留许可声明；系统开启减少动态效果时直接显示终态。

## 不要这样用

- 每一页都放同一种条形图或进度条。
- 把柔和阴影、细边框、胶囊按钮混进来——那是现代 SaaS 的语言，跟这套冲突。
- 单侧放内容，另一侧空着。
- 给配色库的小卡用「当前主题色」当边框和底色，那 17 张卡会全部长成一个样。
- 用图标库的矢量图标代替手绘涂鸦。
