## 变量映射

模板里的变量名与角色一一对应：

```
--bg          背景
--ink         标题
--para        正文
--accent      按钮 / 主强调
--accent-ink  按钮上的文字
--soft        次要色（插画、第二档填充）
--mint        第三色（插画、第三档填充）
```

卡片底色、细线、标签底色不要写死，由当前配色推导，否则切到深底会失效：

```css
--card: color-mix(in oklab, var(--ink) 4%, var(--bg));
--line: color-mix(in oklab, var(--ink) 14%, transparent);
--chip: color-mix(in oklab, var(--accent) 26%, var(--bg));
```

## 加第 18 套

在模板的 `:root[data-palette="p18"]` 里补齐七个角色值，并在 `PALETTES` 数组里加一项（背景、按钮、次要、第三、标题色），配色库页会自动多一张卡。不要只改一半——缺任何一个角色值，深底或浅底一定有一处读不清。

## 选哪套

按听众和场景挑，不按个人喜好：

- 严肃答辩、技术评审 → 03、08、11、14
- 观点表达、宣讲、课程汇报 → 15、01、05、17
- 创意项目、社团活动 → 07、12、13
- 需要在暗环境投影 → 04、10、12、13、16

选完一套后整份汇报只用这一套，不要每页换色。配色库页是唯一的例外——它展示的是全部可选皮肤。

## 换色怎么操作

模板里换色是实时的，选配色不用改代码：

- 按 `[` 切到上一套，按 `]` 切到下一套，整份汇报立刻跟着变。
- 在配色库页点任意一张小卡，直接跳到那一套，卡片描边标出当前这套。
- 这两个操作只碰配色，不占用 A、D、左右方向键，翻页行为完全不受影响。

定下配色后，交付前把配色库页删掉，成品只留一套配色；`[` / `]` 快捷键留着无害，想收干净也可以一并删掉。
