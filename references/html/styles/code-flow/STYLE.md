# 流式代码风

全套使用暖雪色 `#efeee9` 作为页面底色，近黑色 `#232323` 用于正文和字符流。次要文字、边线和字符密度用近黑色的透明度区分。标题用无衬线字体，代码、文件名和页码用等宽字体。

封面顶部是横贯全宽的静态黑色字符带，约占投影画面四分之一。浅色等宽字符沿弧线排列，弧线之间留出点状间隔。色带下沿按字符网格形成高低错开的阶梯，少量黑色字符散入下方暖雪色区域。中段保留大面积留白，主标题和副标题安排在左下，作者、日期或主题信息可放在右侧。[The Content Architecture](https://www.contentarchitecture.dev/)

内容页采用暖雪色纯底。投影时左右分栏，一侧安排标题和说明，另一侧放项目图、截图或证据，窄窗口上下排列。图片和图注使用留白分组。表格按需用横线分隔各行。

制作时使用单文件模板。用项目材料替换示例内容，用封面的 `data-flow` 设置字符带中的文件名或项目术语。保留 `.deck > section`、右下角页码和键盘翻页。[单文件模板](../../../../assets/html/styles/code-flow/deck.html)

交付前核对封面字符带和标题之间的留白，以及内容页的图文间距。按共用流程运行离线与翻页验收。
