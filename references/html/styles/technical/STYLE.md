# 古典科技风

以旧科学图册和仪器制图为视觉参照。用标题、内容主图和明暗对比建立层级，用小型科学图案点缀。按 [版式规则](layouts.md) 选择构图，并遵守 [HTML 共用基准](../../design-baseline.md)。

## 主体与点缀

- 封面以标题或与主题直接相关的画面为主体。内容页把主要空间留给本页的关键图表、照片、结构或数据。
- 原子、试管、烧瓶和仪器刻度以小型线描点缀出现。可以放在章节号旁、图注边缘或明暗交界的空处。以 1280 × 720 为参照，单个符号的较长一边通常为 24–48 像素。每页通常选一处，版面需要时可以省略。
- 小图案用少量线条保留可辨识的形状，视觉分量低于标题和主体图。原子、试管等轮廓可以作为图册记号，具体关系和数据交给正文、主图和图注表达。

## 纸面与明暗

- 默认使用象牙色 `#EEE9D7`、墨黑 `#181916`、朱红 `#B83B2E`。象牙色作为主要纸面，墨黑用在需要形成明暗对比的区域。深区里的主要文字反白，朱红集中用于关键节点、边界标记或数据。
- 封面、章节页或确有边界的机制页，可以用墨黑断面突出标题、主体图或内容转折。根据主体的位置决定暗区的大小和形状，保持整页有一个视觉重点。规则的边界用直线，表现突变时可用斜切或不规则断口。
- 投影使用 16:9。内容页的标题从左上同一位置起排，主体图在标题下方展开。维持相同的页边距，给图、标线和标签留出空间。

## 文字、图形与动效

- 主标题用大号无衬线字。用等宽字排技术标识符、采样时间、单位和图号。标注贴近实际指向的节点、线段或读数。
- 辅助刻度比主体轮廓淡，边线只用于标明区域范围，强调线标出讲述重点。主体轮廓、结构线和标线用不同线宽或对比度区分。
- 用 GSAP 依次呈现讲述需要的主体、路径或数据标记，小型点缀保持静止。动效结束后图和文字完整可读，系统设置减少动态效果时直接展示完整状态。
