# HTML 汇报页设计基准

制作新汇报页或美化已有汇报页时，按这份基准设计并逐页检查。各套风格共用这份基准。

## 风格选择

必须根据汇报的主题和内容选定适合的设计风格，并结合选定风格的规则与本基准设计页面。用户指定风格或项目已有设计规范时，遵循相应要求。

## 交付形式

每份汇报交付一个可直接打开的 `.html` 文件。CSS、JavaScript 和展示所需的库、图片及数据都嵌入文件，使用系统字体或嵌入字体文件。用浏览器直接打开该文件即可离线展示和翻页。来源链接可以保留，页面展示所需内容存放在文件内。

## 配色

选色尽量少，每张汇报页最多使用三种设计用色。页面主动选用的背景色、文字色、强调色和装饰色共同计入。多页汇报优先沿用同一套颜色。

角色化色板是这条规则的例外：一套配色按「背景 / 标题 / 正文 / 强调 / 强调上的文字 / 次要 / 第三」分工，整份汇报只用其中一套，颜色虽然多于三种，但每个角色只有一个值，不额外挑色。使用这类风格时按它的色板表选一套，不逐页换色。

## 底色与文字

每块底色配一套前景色，文字只出现在它所属的那块底色上。

- 浅底配深字，饱和底配浅字：米色、白色、黄色底用墨色文字，蓝、深蓝、深绿这类饱和底用米色或白色文字。
- 文字不跨越底色交界。内容放不下时删内容或拆页，不把正文挤到纸外。
- 强调色只在浅底上使用。深红、赭色在米色上可读，放在饱和底上对比不足，改用该底色的前景色。
- 板下批注是独立角色：允许放在纸面之外的底色上，用手写体、该底色的前景色和一支手绘箭头指回纸面，一条不超过一行，字号比正文小一档。它不承担结论，只补充一句语气。

## 渐变

背景和大面积色块优先使用纯色。渐变只用于少量局部元素，保留清晰的文字和图形。

## 动效

每页入场都要有动效，按讲述顺序把标题、正文、图表和图注依次带入，不只用整页淡入。**所有汇报页一律用 GSAP 时间线实现**，交付前按 [强制内联 GSAP](workflow.md#交付前强制内联-gsap) 运行一次，并按 [动效规则](motion.md) 组织每页的入场。系统开启减少动态效果时直接显示终态，不播动画。动效结束后，正文、数据和图注应完整可读。

## 翻页和页码

每次只显示当前汇报页。翻页只有两个键：按 A 或左方向键返回上一页，按 D 或右方向键进入下一页；页内步骤、展开、悬停等任何交互都不得占用这四个键。第一页和最后一页到达边界后停留在当前页。滚轮和上下方向键只用于在当前页内浏览。投影尺寸下当前页在一屏内展示。页面的翻页界面只在右下角显示页码，省去翻页按钮和按键提示。

## 页面文字

保留标题、关键证据和读懂内容所需的文字。省去复述标题、重复图表结论和泛泛引导听众阅读的小字。图表保留必要的单位、口径和来源，口头过渡放入讲稿。

## 图文布局

内容页结合简明文字与有助于理解项目的图片、截图、图表或示意图。单张大图优先居中，多张图片优先对称排列。图文并排时，安排好两侧的内容和留白，让图和解释文字彼此对应。大图与简短说明可以上下排列并居中，避免单侧放置大图后，另一侧留下大面积空白。
