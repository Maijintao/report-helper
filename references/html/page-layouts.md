# 整页版式

按听众需要看的证据选择版式，版式和字体、纸面、用色分别决定。参考 [离线汇报交付示例](../../examples/report-helper-demo/汇报页.html) 和 [配套讲稿](../../examples/report-helper-demo/逐字稿.md)，HTML 源码中的注释说明了页面取舍。

| 页面用途 | 主体与阅读顺序 | 入场安排 |
| --- | --- | --- |
| 开场与使用场景 | 项目名称或使用场景占主要区域。把一句任务说明、演示环境或成果放在近处。示例第 1–2 页分别用标题与交付物、场景与按键。 | 先给听众一个主题，再出现能看懂的对象或操作。 |
| 产品截图 | 给真实画面分配主要宽度，先裁到与当前操作有关的范围，再用短标注指出输入、状态或结果。图注紧靠图，口头说明负责解释证据。 | 先展示整张截图，再按讲述顺序出现一两处标注。 |
| 系统关系与过程 | 关系图突出本次讲解的输入、关键模块和结果。步骤用有序结构。示例第 3 页用三步解释交付，窄窗口保持同一顺序。 | 标题出现后沿调用方向或步骤推进。 |
| 结果或验证范围 | 重点数字与单位、口径、样本量相邻。按读数任务选择数字卡、同尺度图表或短表格。示例第 4 页用表格呈现三个真实的验收尺寸和对应项目。 | 同一条证据一起出现，数据表可整体出现。 |
| 演示交接 | 放将要执行的操作和期待看到的结果，命令只保留现场要运行的部分。示例第 5 页用两栏对应浏览器操作和终端验收。 | 操作与预期结果依阅读顺序出现，完成后保持静态。 |

先确定主体，再添加说明。投影空间不足时，优先保留本页观点和支撑它的画面或数字。次要解释、长命令和检查过程放入讲稿或备查材料。沿用同一套标题位置、字号层级、留白与色彩，由证据的形状和阅读顺序决定版式。
