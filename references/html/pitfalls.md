# 常见问题清单

制作和检查汇报页时逐条对照。下面每一条都在现场出过问题。

## 内容

- 整页贴代码块。听众读不完，也看不清。把代码缩短到能一眼看懂的三五行，完整的实现放进逐字稿或问答备稿。
- 把逐字稿的句子抄到页面上。页面放结论和证据，讲述的句子留在稿子里。
- 一页塞两个结论。听众会不知道先看哪个。一页一个结论，多的拆到下一页。
- 图表没有单位、统计范围或来源。数字旁边必须能读出它是什么、覆盖谁、什么时候。
- 用「提升明显」「效果很好」代替具体数字。换成百分比、耗时、覆盖的场景数。
- 把计划中的结果写成已完成。用「已实现」「已验证」「计划中」区分开。

## 版式

- 投影字号过小。以 1280 × 720 为参照，标题不小于 32 像素，正文不小于 24 像素，图注不小于 18 像素。
- 设计用色超过三种。背景、文字、强调各自一种，装饰从这三种里取。
- 大面积渐变或高饱和底色。文字对比度掉下来，投影仪上更难读。
- 表格行数过多，为了塞下而缩小字号。超过八行就拆页，或者只保留结论行。
- 中英文和数字之间不留空格，读起来挤在一起。
- 单侧放一张大图，另一侧留出大片空白。图文并排时两侧分量要接近。

## 交付

- 用 `<script src>` 或 `<link href>` 引外部资源。断网现场直接白屏，验收脚本也会判失败。
- 图片、字体用相对路径引用。换一台机器打开就缺图。位图和字体转成 data URL 内嵌。
- 页码写成「1」或「第 1 页」。验收脚本要求「当前页 / 总页数」的格式。
- 页面上出现翻页按钮或页内导航链接。翻页只靠键盘，界面只留右下角页码。
- 投影尺寸下出现纵向滚动。内容要在一屏内展示，装不下就减少内容。
- 动效结束后元素停在透明状态。交付前把每一页从头看到尾。
- 打印时缺页。设置了隐藏的页面在打印样式里要恢复显示。
