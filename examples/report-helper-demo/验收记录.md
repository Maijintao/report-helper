# 示例验收记录

验收日期：2026 年 11 月 6 日。

> 这是一份历史记录，只对应当时的脚本与文件范围。之后新增了 GSAP 动效校验（`check-pagination.js` 会在允许动效的条件下重跑一遍，检查库是否内联、每页播完内容是否可见），也新增了暖纸手记风与自然多色风，本记录未覆盖这些内容。需要当前结果时重新运行验收命令。

## 检查对象

- 页面：`examples/report-helper-demo/汇报页.html`
- 模板：`assets/html/base.html` 与 `assets/html/styles/` 下当时已有的模板，一并运行
- 检查逻辑：`scripts/check-pagination.js`，由 `scripts/check-deck.mjs` 调用

## 运行环境

Node.js v22.22.2，playwright-core 1.65.0，Chrome。本机 Chrome 自带的沙箱无法初始化，运行时追加 `--no-sandbox`。

```sh
node scripts/check-deck.mjs examples/report-helper-demo/汇报页.html \
  assets/html/base.html \
  assets/html/styles/paper/deck.html \
  assets/html/styles/cartoon/deck.html \
  assets/html/styles/code-flow/deck.html \
  assets/html/styles/line-art/deck.html --no-sandbox
```

## 脚本覆盖的范围

脚本断开浏览器网络后重新加载页面，检查是否请求其他本地文件或网络资源。随后在 1440 × 900、1280 × 720 和 390 × 844 三种窗口尺寸下实际发送按键，检查单页显示、首页与末页边界、右下角页码和可见翻页控件，投影尺寸另检查纵向滚动与滚轮。
